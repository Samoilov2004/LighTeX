# Mathematical Notes

Edit the title-page metadata in `main.tex`. Copy
`chapters/_chapter-template.tex` for every new chapter, then add the file with
`\include{chapters/file-name}`.

Available environments include `definition`, `theorem`, `lemma`,
`proposition`, `corollary`, `proof`, `problem`, `solution`, `example`,
`remark`, `notation`, and `summary`.

Build with:

```bash
make pdf
```
